### Task 8 - Iterator and Generator

Created a custom iterator that returns numbers from **1 to 10**.

Created a generator function that returns **even numbers from 1 to 50**.

Also compared the memory usage of:

- A list containing one million numbers
- A generator containing one million numbers

#### Memory Comparison Observation

A list stores all the values in memory at the same time, so it requires more memory.

A generator produces values one at a time when they are needed instead of storing all the values in memory.

Therefore, a generator uses much less memory than a list when working with a large amount of data.

**Conclusion:** Generators are more memory-efficient than lists for handling large amounts of data.

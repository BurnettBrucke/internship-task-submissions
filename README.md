## Day 1 Tasks

### Task 1 - Python Basics and Input Handling

• Take name, age, email and city from the user and display a formatted introduction.
• Build a calculator for addition, subtraction, multiplication, division and modulus.
• Convert Celsius to Fahrenheit.
• Calculate rectangle area and perimeter.
• Calculate a salary after an 18 percent increment.
Requirements
• Validate numeric input.
• Handle empty input.
• Prevent division by zero.
• Show meaningful messages.

### Task 2 - Conditions and Loops

• Check positive, negative or zero.
• Check even or odd.
• Find the largest of three numbers.
• Print a multiplication table.
• Calculate the sum from 1 to n.
• Check whether a number is prime.
• Print even numbers from 1 to 100.
**Use functions for at least three programs, demonstrate both for and while loops, and avoid
repeated code.**

### Task 3 - String Operations

• Reverse a sentence.
• Check whether a word is a palindrome.
• Count vowels and consonants.
• Count total words.
• Remove extra spaces.
• Count character frequency.
• Find the first non-repeating character.
**Handle empty strings and case differences. Do not use an external library.**

### Task 4 - Lists and Dictionaries

• Find the largest and smallest list values.
• Find the second-largest distinct number without sorting the complete list.
• Remove duplicates while preserving order.
• Separate even and odd numbers.
• Find common values between two lists.
• Count frequency of each number.
• Create a marks dictionary and find the highest scorer, lowest scorer and average.
**Handle empty lists and duplicate values.**

### Task 5 - Student Manager

Implemented a menu-driven Student Management System.

Build a menu-driven program with these options:
• Add a student and marks for three subjects.
• Update marks.
• Delete a student.
• View all students.
• Search by name.
• Calculate total and average.
• Display pass or fail.
• Display the highest-scoring student.
• Exit.
**Project Rules**
• Use a dictionary and separate functions.
• Prevent duplicate student names.
• Marks must be from 0 to 100.
• Pass only when all three marks are at least 40.
• Handle invalid menu choices.
• Bonus: save and load data using JSON.

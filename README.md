# Burnett Brucke Pvt Ltd – Internship Task Submissions

Welcome to the Burnett Brucke Pvt Ltd internship task repository.

This repository contains task instructions and submission guidelines for interns. Each intern must create their own GitHub repository for the assigned task and submit the repository link.

## How to Submit Your Work

1. Create a new public GitHub repository in your own GitHub account.
2. Complete the assigned task in your repository.
3. Add a clear README file explaining:
   - Project name
   - Features completed
   - Tech stack used
   - How to run the project locally
   - Screenshots if applicable
4. Push your complete code to GitHub.
5. Share your repository link with the Burnett Brucke team.

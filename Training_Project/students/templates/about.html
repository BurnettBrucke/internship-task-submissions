About Our System

A simple and efficient Student Management System developed as part of the Bug Network Private Limited Training Program.

About the Project

The Student Management System is a Django-based web application designed to manage student information easily and efficiently.

The application allows authorized users to add, view, update, and delete student records through a simple and user-friendly interface.

This project demonstrates important Django concepts such as models, views, templates, forms, URL routing, authentication, database operations, and CRUD functionality.

Key Features

👨‍🎓

Student Management

Add, view, edit, and delete student records easily using the management system.

🔐

User Authentication

Secure registration, login, and logout functionality using Django authentication.

📊

Student Information

View student details including name, email, age, course, marks, and active status.

Training Program

This project is developed as part of the Bug Network Private Limited Training Program. It provides practical experience in Django development, database management, authentication, CRUD operations, and building web applications using Python.

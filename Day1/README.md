# Day 1 – Python Tasks

This folder contains the Python tasks completed as part of **Day 1** of the internship.

# Overview

The project consists of **five Python files**, where each file contains a different task. Each task includes multiple functions that are defined and implemented to handle different requirements and scenarios.

The code also covers various **edge cases and input scenarios** to ensure the programs work reliably.

## Prerequisites

Before running the programs, make sure you have:

-> Python 3.x installed and configured on your system.
-> A code editor or IDE such as VS Code, PyCharm, or any other Python-supported IDE.

You can verify your Python installation using:

```bash
python --version
```

##  How to Run

You can run any Python file from the terminal using:

```bash
python filename.py
```

For example:

```bash
python task_1.py
```

Alternatively, you can open the file in your preferred IDE and use the **Run** option.

##  Functions

Each Python file contains multiple functions for different operations.

Some functions may be provided as individual implementations for specific requirements. To execute a particular function, uncomment the corresponding function call in the file and run the program.

For example:

```python

```

can be uncommented as:

```python
function_name()
```

and then executed using:

```bash
python task_1.py
```
